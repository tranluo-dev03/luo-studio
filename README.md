# LUO Studio

Tao hang loat video quang cao dang hoi thoai (xem `HUONG-DAN.txt` de biet cach dung chi tiet).

## Cai dat tu ma nguon (Windows 10/11, 64-bit)

1. Cai Python 3.11: `winget install Python.Python.3.11`
2. Clone repo (khong tai ZIP de tranh bi danh dau "tai tu internet"):
   ```
   git clone <URL-repo> LUO-Studio
   cd LUO-Studio
   ```
3. Cai dat mot lan:
   ```
   powershell -ExecutionPolicy Bypass -File setup.ps1
   ```
4. Chay: bam `LUO Studio.bat` (hoac `LUO Studio (xem loi).bat` de xem log).

Du lieu nguoi dung nam trong `userdata/` va khong duoc dua len git.
